# IC2 核电增强系统设计方案（v1 草案）

> **定位**：本文是一份**纯设计/分析方案**，不包含已落地的代码改动。目标是把 IC2 核电从「数值被 ASA 太阳能碾压、机制浅、玩家不用」的现状，重构为一套**数值有竞争力、机制有深度、收益与成本/风险严格匹配**的增强核电体系。
>
> 配套现状文档：[`nuclear-power.md`](nuclear-power.md)、[`heat-system.md`](heat-system.md)。
> 数值口径：均以本仓库 Kotlin 源码（`core/src/main/kotlin/ic2_120/...`）和 `reactor-simulator/src/sim/constants.ts` 为准，已交叉验证。

---

## 0. 摘要（TL;DR）

**问题**：IC2 核电满配（流体堆 ~1k–3k EU/t，占地 125 方块、有爆炸风险、需持续维护），而 ASA 量子面板单方块零维护就有 4096 EU/t，工业升级中子面板高达 **16,777,216 EU/t**——核电在每个维度都被碾压。

**根因**：① 数值断层（核电天花板比 ASA 低 3–4 个数量级）；② 机制过浅（只有「脉冲计数 + 热量池 + 二值爆炸」三个维度，缺乏真实核物理的中子学、增殖、衰变、临界、辐射）；③ 没有任何「越难越强」的收益曲线，玩家没有任何理由钻研。

**方案**：引入 **6 大新机制**（中子能谱慢化、同位素增殖闭环、临界态反应性控制、衰变余热、分级熔毁辐射、磁约束聚变）和 **35+ 新器件**，建立 5 档功率阶梯（T1 增强裂变 → T5 反物质/奇点），让核电通过**叠加放大机制**达到 2M–20M EU/t 的天花板，与工业升级中子面板对标；但每一档都需要**链式科技前置 + 更大的占地 + 更高的操作复杂度 + 更高的爆炸/辐射风险**来支付成本。

**旗舰新机制器件**（详见 §6）：
1. **同位素增殖毯**——吸收中子脉冲把内部材料转化为新同位素（铀→钚、钍→铀-233），实现真正的核燃料循环；
2. **中子慢化器**——把快中子脉冲转为「热中子」，解锁新型燃料的裂变截面，引入中子能谱布局维度；
3. **红石控制棒**——红石强度 0–15 线性吸收中子，实现精密功率调节与紧急停堆。

### 1.2 现有机制的天花板

现有反应堆只有三个物理维度，且都偏简单：

1. **脉冲计数（中子学）**：`neighborPulses = Σ四邻 acceptUraniumPulse`，每个邻居**扁平贡献 +1**（`UraniumFuelRods.kt:30-49` 的 `checkPulseable` 返回 0/1，与邻居是单/双/四联棒无关）。这导致密集 quad 棒布局的互脉冲收益远低于上游 IC2 exp（exp 中双联邻居贡献 2、四联贡献 4）。
2. **热量池（热力学）**：堆温 `0..maxHeat`，`maxHeat = 10000 + 500×#plating + 1700×#heat_plating`。组件热量靠邻接 `alterHeat` 流动。散热片蒸发是「凭空消失」（电模式）或转冷却液（流体模式）。
3. **二值爆炸（安全）**：堆温 ≥ 10000 直接核爆，中间无渐进。环境效果（火/蒸发水/岩浆/伤害）只是 `applyHeatEffects()` 的副作用，不构成「机制」。

**现实功率天花板**（实测/推算）：
- EU 模式满配（6 仓 54 槽 + quad 棒 + 反射器 + 散热）：稳定 Mark I 约 **1k–1.5k EU/t**。
- 流体模式满配（5×5×5 + 蒸汽涡轮链）：约 **1k–3k EU/t**（受 `SteamGenerator` 1200 HU/t 与 `KineticGenerator` 512 EU/t 上限约束，需多组并联）。

### 1.3 与 ASA 的数值鸿沟

| 维度 | IC2 核电满配 | ASA Quantum | 工业升级 Neutron |
|---|---|---|---|
| **EU/t 峰值** | ~1k–3k | 4,096（昼）/2,048（夜） | **16,777,216**（全天） |
| **占地** | 125+ 方块 | 1 | 1 |
| **维护** | 高（换棒/防爆/流体平衡） | 零 | 零 |
| **爆炸风险** | 高 | 无 | 无 |
| **数值倍率（核电=1）** | 1× | ~2× | **~8000×** |

**结论**：ASA Quantum 已抹平核电全部优势；工业升级把天花板拉到核电的 8000 倍。核电仅存的差异化只剩「不依赖昼夜/不需露天」，纯数值上已无竞争力。

## 2. 根因分析：玩家为什么抛弃核电

1. **绝对数值断层**：核电天花板 3k EU/t，ASA 中端面板（Ultimate 512）就开始追平，高端（Quantum 4096）直接碾压，工业升级更是 4–5 个数量级差距。玩家算一笔账就知道不值得。
2. **缺乏「越难越强」的曲线**：现有核电只有「铀→MOX」两级，且 MOX 仅仅是「铀 ×温度系数」，没有质的飞跃。玩家从铀到 MOX 几乎没有新机制要学，钻研没有回报。
3. **机制浅 → 没有可钻研深度**：脉冲是扁平计数、爆炸是二值、没有增殖闭环、没有辐射、没有控制理论。玩家摆出最优布局（查 wiki 抄一个 Mark VI）后就无事可做，「核电」本质上是个查表填空题。
4. **风险/回报倒挂**：核电有爆炸风险、需要持续维护、占地巨大，**结果**反而比零风险的太阳能弱——这是典型的「惩罚了付出却没奖励回报」。
5. **核燃料循环断裂**：乏燃料棒离心→钚→MOX 是 IC2 经典链，但本实现里 `lithium_fuel_rod`、`depleted_isotope_fuel_rod` 都是裸占位 Item，增殖链未实装，钚/MOX 之外没有新燃料可玩。

## 3. 设计哲学与平衡框架

### 3.1 四条设计原则

1. **复杂度即收益**：每引入一层新机制（慢化、增殖、临界、聚变），功率上限必须显著抬升。玩家「学会并驾驭」新机制的脑力付出，必须能兑换成 EU。
2. **风险与回报同向放大**：高功率档位必须有更高的爆炸威力、更宽的辐射污染半径、更难维护的燃料循环。不能出现「免费的高功率」。
3. **链式科技前置**：高 tier 燃料/材料必须是低 tier 反应堆的**产物**（铀→钚→浓缩铀→聚变燃料→反物质），形成必须层层解锁的科技树，杜绝跳级。
4. **保留 IC2 风味，引入真实核物理概念**：所有新机制都对应真实核工程概念（慢化、增殖、临界、衰变热、辐射、聚变、磁约束），让「核电玩家」有专业感，而不是凭空发明魔法方块。

### 3.2 风险-回报曲线

```
功率(EU/t)
  ^
  |                          ★ T5 反物质/奇点 (2M-20M) —— 灾难级爆炸，全球辐射
  |                     ★ T4 磁约束聚变 (200k-3M) —— 极窄温窗，瞬时熔毁
  |                ★ T3 临界态+增殖闭环 (50k-300k) —— 临界态失控即核爆
  |           ★ T2 临界态流体堆 (20k-100k) —— 高辐射，需屏蔽结构
  |      ★ T1 钚/钍增强裂变 (1k-15k) —— 常规爆炸，局部辐射
  |  ★ 现状铀/MOX (~3k) —— 仅二值爆炸
  +---------------------------------------------> 复杂度/风险/成本
```

### 3.3 成本-收益匹配（不是免费午餐）

每个高数值档位都同时支付**四种成本**：
- **材料成本**：链式科技，高 tier 燃料必须由低 tier 反应堆产出（增殖）。
- **占地成本**：流体链、屏蔽外壳、聚变腔，几何级数增长。
- **操作成本**：临界态需精密红石控制、聚变需维持温度窗口，玩家不能离线挂机。
- **风险成本**：爆炸威力放大（受燃料总量加成）、辐射污染半径放大、衰变热使「紧急停堆」也不能立即安全。

## 4. 六大新机制

### 4.1 中子能谱与慢化（中子学深化）

**现状缺陷**：脉冲只有「有/无」二元状态，每个邻居贡献 +1，无法体现中子能量。

**新机制**：引入「快中子 / 热中子」二能谱。
- 燃料棒裂变释放**快中子**（现有脉冲）。
- **中子慢化器**（新器件）放在中子传播路径上，把经过的快中子转为**热中子**。热中子：
  - 对**新型燃料**（钍-232、铀-238 增殖型、钚-239）有效——这些燃料**只有热中子才能引发裂变或增殖**。
  - 对**传统铀/MOX**无效（它们用快中子），但会被**中子毒物**（控制棒）更高效地吸收。
- 玩家必须在布局里**规划中子路径**：「燃料棒 → 慢化器 → 增殖毯/钍棒」，形成类似真实反应堆栅格的拓扑。

**实现要点**：在 `IReactorComponent.acceptUraniumPulse` 增加一个 `isThermal: Boolean` 参数；慢化器拦截并改写脉冲属性。详见 §6.2。

### 4.2 同位素增殖闭环（核燃料循环）

**现状缺陷**：乏燃料棒离心→钚链断裂（`depleted_isotope_fuel_rod` 是占位），没有「增殖」概念，燃料是一次性消耗品。

**新机制**：**增殖毯**（新器件）不发电、几乎不产热，只吸收中子脉冲并积累「增殖进度」。满进度后转化为对应的增殖产物：
- 铀-238 毯 + 热中子 → **钚-239**（`depleted_isotope_fuel_rod` 实装）
- 钍-232 毯 + 热中子 → **铀-233**（新顶级裂变燃料）
- 锂-6 毯 + 中子 → **氚**（聚变燃料，`lithium_fuel_rod` 实装）

玩家可以在反应堆里**预留增殖位**，用「主燃料棒发电 + 副增殖毯产新燃料」的双目标布局。这是真实核工程的「转换比 > 1 增殖反应堆」概念。

**收益**：每个高 tier 燃料都是低 tier 堆的产物，强制链式解锁，且让反应堆从「纯发电」变成「发电 + 燃料工厂」。

### 4.3 临界态与反应性控制（控制论）

**现状缺陷**：反应堆只有「红石开关」(fuelActive boolean) 一档控制，没有功率调节概念。

**新机制**：
- 引入**反应性系数 k**（中子倍增因子）。`k = 产出中子 / 消耗中子`。`k<1` 次临界（功率衰减熄火）、`k=1` 临界（自持）、`k>1` 超临界（功率指数增长→爆炸）。
- **临界态奖励**：当堆内中子密度（用 `ΣneighborPulses` 衡量）维持在临界窗口（如 `k ∈ [0.95, 1.05]`）时，**所有燃料棒 EU 输出 ×2~×3**（链式反应自持增益），但产热同步放大。
- **红石控制棒**（新器件）：红石强度 0–15 对应吸收 0%–100% 中子。玩家用红石电路**精密调节 k**，让堆运行在临界窗口，吃满增益而不超临界爆炸。
- **超临界惩罚**：`k>1.05` 时热量与 EU 指数上升，几秒内必然熔毁——必须能快速插控制棒「紧急停堆」。

**玩法**：核电从「摆好静态布局」变成「需要红石 PID 控制器维持临界」的动态系统，引入真正的工程挑战。

### 4.4 衰变热与停堆余热（热力学真实性）

**现状缺陷**：燃料棒红石一关就完全停热，可以立即安全拆解，缺乏真实核工程的「余热」概念。

**新机制**：
- 燃料棒/反应堆停堆（红石断电或拔棒）后，**仍持续产热一段时间**（指数衰减，半衰期 ~60s），热量正比于停堆前的功率水平。
- 高功率堆的衰变热可能高达满功率的 5–10%，足以在冷却中断时**持续升温直至熔毁**。
- 含义：① 不能「关了就走」，必须维持冷却液循环直到衰变热排尽；② 乏燃料棒从堆里取出后仍需在水池里冷却一段时间才能安全处理。

**实现要点**：在 `NuclearReactorBlockEntity` 增加 `decayHeatBuffer`，停堆后按 `decayHeatBuffer *= 0.99` 衰减并注入堆温。

### 4.5 分级熔毁与辐射污染（安全机制）

**现状缺陷**：爆炸是二值（<10000 安全 / ≥10000 核爆），中间只有无关紧要的环境副作用。无法表达「接近极限运行」的渐进危险。

**新机制**：分级事故模型。

| 堆温区间 | 事故等级 | 后果 |
|---|---|---|
| 0–7000 | 安全 | 无 |
| 7000–8500 | 泄漏 | **辐射污染**：以反应堆为中心半径 R 的区块写入「辐射值」，持续伤害生物、使作物变异/死亡、使水带辐射 |
| 8500–9500 | 熔穿 | 局部方块变岩浆、破坏相邻方块、辐射半径扩大 |
| 9500–10000 | 局部爆炸 | 中等爆炸（受隔板抑制）+ 大范围辐射 |
| ≥10000 | 核爆 | 大威力爆炸（受燃料总量加成）+ 巨大辐射云 |

**辐射系统**（新数据层）：
- 用一张「区块辐射强度」映射（chunk-level radiation map）记录污染。
- 辐射值随时间缓慢衰减（半衰期，可配置），下雨加速洗刷。
- 玩家需用**铅板/混凝土屏蔽结构**包裹反应堆降低辐射泄漏半径，或用**去污机**清理污染区块。
- **辐射屏蔽板**（实装 `containment_reactor_plating`）：放入反应堆降低辐射泄漏半径，但不加热容（与 plating 区分定位）。

### 4.6 磁约束聚变（新能源形态，T4 天花板）

**现状缺陷**：所有能源都是「裂变 + 蒸汽」链，没有根本不同的新形态。

**新机制**：全新的**聚变反应堆**（独立多方块结构，不复用裂变腔）。
- 燃料：**氘 + 氚**（氘来自重水电解，氚来自锂增殖棒，见 §4.2）。
- 机制：聚变不靠中子脉冲产热，而是维持一个**等离子体温度窗口** `[T_min, T_max]`。
  - 低于 `T_min`：聚变熄火，输出归零（需重新点火）。
  - 在窗口内：输出 EU 正比于温度（越高越强）。
  - 高于 `T_max`：磁约束失效，**瞬时大爆炸**（聚变失控）。
- **磁约束线圈**（新器件，放入聚变腔）：提供「约束强度」，扩大 `T_max` 上限，但消耗大量 EU 维持（自身耗电）。
- 点火需要外部大功率能量注入（类似托卡马克启动），用 IC2 的高 tier 能量系统。
- **中子屏蔽**（新）：聚变（D-T 反应）释放高能中子，必须有中子屏蔽层吸收，否则伤害生物/激活周围裂变燃料。

**数值**：D-T 聚变单堆目标 **200k–3M EU/t**，但温度窗口极窄、需持续供电维持磁场、点火昂贵、失控即灾难。

## 6. 旗舰新器件深入设计（用户特别要求）

### 6.1 同位素增殖毯（`breeding_blanket_*`）

> 这是本方案最核心的「放入反应堆、具有全新机制」的器件。它把反应堆从「纯发电」变成「发电 + 燃料工厂」。

#### 机制
- 放入反应堆槽位，**不发电、产热极低**（仅为被中子照射时的少量沉积热）。
- 实现 `IReactorComponent.acceptUraniumPulse`，但**只接受特定能谱的中子**：
  - U-238 毯：接受热中子（需经慢化器）。
  - Th-232 毯：接受热中子。
  - Li-6 毯：接受任意中子（快/热均可）。
- 每接受 1 个有效脉冲，内部 `breedProgress += 1`（用 NBT 存储，类似耐久条但反向——填满即完成）。
- 达到阈值 `breedThreshold`（建议 2000–5000 脉冲，约 1–2 个游戏日）时，槽位**转化为对应产物 ItemStack**：
  - U-238 毯 → 1× `plutonium_nugget` ×N（凑成锭需多个毯）。
  - Th-232 毯 → 1× `uranium233_nugget`。
  - Li-6 毯 → 1× `tritium_cell`（氚单元，聚变燃料）。

#### 数值（建议）
| 类型 | 注册名 | breedThreshold | 产物 | 产物用途 |
|---|---|---|---|---|
| U-238 毯 | `breeding_blanket_u238` | 3000 脉冲 | 4× plutonium_nugget | → 钚锭 → F4 钚棒 |
| Th-232 毯 | `breeding_blanket_th232` | 5000 脉冲 | 2× uranium233_nugget | → 铀-233 锭 → F7 |
| Li-6 毯 | `breeding_blanket_li6` | 2000 脉冲 | 1× tritium_cell | → 聚变燃料 |

#### 玩法影响
- 玩家在反应堆布局时，必须**牺牲发电槽位放增殖毯**，形成「主燃料棒 + 增殖副位」的双目标优化。
- 增殖效率取决于中子通量（密集布局、慢化器、反射器配置），让布局复杂度大幅上升。
- 这条链强制实现 §3.1 原则 3「链式科技」：钚/铀-233/氚都**只能**靠增殖获得，无法直接合成跳级。
- 实装 `depleted_isotope_fuel_rod`（U-238 增殖中间态）和 `lithium_fuel_rod`（Li-6 增殖产物占位）两个现有坑位。

#### 代码实现 hook
- 新增 `AbstractBreedingBlanketItem(maxBreed, productSupplier, acceptedSpectrum) : AbstractDamageableReactorComponent`。
- `acceptUraniumPulse(..., isThermal)`：检查能谱匹配，匹配则 `breedProgress++`，满则 `reactor.setItemAt(x,y, productStack)`。
- 不实现 `processChamber` 的发电/产热分支（或仅注入微量沉积热）。

### 6.2 中子慢化器（`neutron_moderator`）

#### 机制
- 放入反应堆槽位，**自身不发电、可储热**（热容 5000，吸收慢化过程中沉积的热）。
- 它**改写经过它的中子能谱**：当一个燃料棒的脉冲「经过」慢化器到达对侧时，标记为热中子。
- 实现方式（最小侵入）：在 `IReactorComponent.acceptUraniumPulse` 签名增加 `vararg spectrumFlags` 或一个 `PulseContext`（含 `isThermal`、`originRod`），慢化器作为「中继」：燃料棒向四邻发脉冲时，若邻居是慢化器，慢化器**向其另一侧的器件转发一个热中子脉冲**（并自身升温）。

#### 数值（建议）
| 器件 | 热容 | 慢化产热/脉冲 | 损耗 | 材料 |
|---|---|---|---|---|
| neutron_moderator（石墨） | 5000 | +2 HU | maxUse 60000（辐照损耗） | 石墨块 ×4 + 铅 ×4 |
| advanced_neutron_moderator（重水） | 8000 | +1 HU | 无损耗 | 重水桶 ×1 + 石英 ×4 |

#### 玩法影响
- 解锁 F6 钍棒、F7 铀-233 棒（**仅热中子裂变**）、B1/B2 增殖毯（**仅热中子增殖**）的全部玩法。
- 引入「中子路径规划」：玩家必须让快中子从燃料棒出发，**经过慢化器**到达钍棒/增殖毯，形成有方向性的栅格布局。
- 让密集布局不再是「quad 棒互相照射」单一最优解，而是「裂变区 + 慢化区 + 增殖区」的功能分区。

#### 代码实现 hook
- 扩展 `IReactorComponent.acceptUraniumPulse` 增加 `PulseContext`（含 `isThermal`）。
- 慢化器实现 `acceptUraniumPulse`：收到快中子 → 向其**来源方向的对侧邻居**转发 `isThermal=true` 的脉冲，自身 `alterHeat(+2)`。
- 这是最小侵入的能谱实现，无需重写整个脉冲传播。

### 6.3 红石控制棒（`control_rod`）

#### 机制
- 放入反应堆槽位，**不发电、不储热、不产热**，唯一的角色是**按红石强度吸收中子**。
- 反应堆读取控制棒所在槽位接收到的红石信号强度 `s ∈ [0,15]`，控制棒**吸收该强度对应比例的邻接中子**：
  - `s=0`：不吸收（堆满功率）。
  - `s=15`：吸收 100%（堆完全停堆，等效 fuelActive=false 但更精细）。
  - `s=8`：吸收约 50%，可把堆压在临界态 `k≈1`。
- 配合 N6 中子通量监测器（输出 k 值到红石比较器），玩家可搭**红石 PID 控制器**自动维持临界态。

#### 数值（建议）
| 器件 | 吸收系数 | 损耗 | 材料 |
|---|---|---|---|
| control_rod | 红石 s/15 × 邻接脉冲 | maxUse 80000（中子辐照损耗，满强度时损耗快） | 硼/碳化硼 + 红石 |
| emergency_scram_rod | 红石脉冲触发后 100% 吸收并锁存 | 一次性（复位需在工作台重置） | 控制棒 + 红石火把 |

#### 玩法影响
- 把核电从「静态布局查表」变成「需要动态控制」的工程系统。
- 临界态增益（§4.3）必须靠控制棒维持，否则 `k>1` 几秒内熔毁——这是高风险高回报的核心。
- C2 紧急停堆棒是「保险丝」：检测到超临界自动插入，牺牲一次性器件保住整个堆。
- 配合 §4.4 衰变热：控制棒插到底停堆，但衰变热仍在，**不能立即安全**，必须维持冷却液循环。

#### 代码实现 hook
- 控制棒实现 `acceptUraniumPulse`：根据所在槽位的红石强度决定是否返回 `false`（吸收），并在 `processChamber` 里按强度消耗耐久。
- 反应堆需在 `processChambers` 前读取每个槽位的红石强度（可通过 `world.getEmittedRedstonePower` 或反应仓端口注入）。

| 临界态增益（N5 + 控制棒维持） | ×2.5 | k≈1 窗口内 |
| 高温增益（类似 MOX 满温 ×5） | ×3 | 铀-233 满温效应 |

> 多堆并联 + 蒸汽机阵列可再 ×N。T4 聚变与 T5 反物质用独立机制突破裂变上限，直接进入 M 级。

### 7.3 与 ASA 的全方位对比（目标态）

| 维度 | 增强核电 T2 临界堆 | 增强核电 T4 聚变堆 | 工业升级 Neutron |
|---|---|---|---|
| **EU/t** | 15k–100k | 200k–3M | 16.7M |
| **占地** | 大（125+屏蔽） | 极大（聚变腔+磁体+屏蔽） | 1 |
| **维护** | 高（换棒+临界控制+辐射清理） | 极高（温度窗口+磁场供电+中子屏蔽） | 零 |
| **风险** | 高（核爆+辐射） | 灾难（瞬时爆炸） | 无 |
| **科技前置** | 铀→钚→铀233 链式 | 氘+氚（增殖）+ 聚变点火 | ASA→工业升级链 |
| **可钻研深度** | 极高（中子学+控制论） | 极高（磁约束工程） | 极低（堆方块） |

**结论**：增强核电在 T2 即超越 ASA Quantum，T4 接近工业升级低端，T5 追平 Neutron。但每个高数值档都付出了 ASA 完全没有的**占地、维护、风险、科技链**成本，符合 §3 的「收益与成本匹配」。

## 8. 玩法 Progression（玩家体验曲线）

```
[新手] 铀棒 EU 模式 5 EU/t → 流体堆 ~1k EU/t （现状入口，不变）
   │  解锁：离心机分离乏燃料 → 钚
   ▼
[T1] 钚/浓缩铀棒 → 单堆 3k–15k EU/t
   │  新学：钚的高产热管理、辐射屏蔽板（实装 containment）
   │  解锁：慢化器、增殖毯（U-238 → 钚 闭环验证）
   ▼
[T2] 重水慢化 + 临界态流体堆 → 15k–100k EU/t
   │  新学：临界态控制论、红石 PID、衰变热、分级熔毁
   │  解锁：钍矿、钍增殖 → 铀-233
   ▼
[T3] 铀-233 增殖闭环 + 液态金属冷却 → 50k–300k EU/t
   │  新学：液氮/液态金属冷却链、屏蔽结构工程
   │  解锁：锂-6 增殖 → 氚、空气液化、聚变点火
   ▼
[T4] 磁约束 D-T 聚变堆 → 200k–3M EU/t
   │  新学：等离子体温窗控制、磁场供电、中子屏蔽
   │  解锁：反物质合成（粒子加速器）
   ▼
[T5] 反物质湮灭反应 → 2M–20M EU/t
      新学：反物质储存（磁悬浮）、湮灭控制
```

每一档**强制**依赖上一档的产物或基础设施，玩家无法跳级；每一档都引入至少一个新机制需要学习，杜绝「抄一个布局用到死」。

## 10. 风险与注意事项

1. **脉冲语义偏差**：现有 `checkPulseable` 扁平 +1（不区分邻居 cell 数），与上游 IC2 exp 不同。新燃料/慢化器的数值平衡**必须基于本实现的脉冲语义**校准，不能直接抄 exp 的 wiki 数值。建议先在 `reactor-simulator` 里建测试用例验证。
2. **不破坏现有存档**：所有新器件用新注册名，不改动现有器件的数值/行为。中子能谱签名扩展用默认参数保持向后兼容（现有组件默认 `isThermal=false`）。辐射系统作为可选特性（`Ic2Config.nuclear.enableRadiation`）。
3. **性能**：临界态 k 值、辐射污染 map、衰变热缓冲都应轻量化（k 值是 O(槽位数) 求和，辐射用 chunk-level 稀疏 map 而非 block-level）。`getMaxHeat()` 已是每帧重算（无缓存），新增隔板类型要确保 `when` 分支效率。
4. **平衡迭代**：本方案数值为「目标区间」，落地后必须用 `reactor-simulator` + 测试服（`develop/wait-done.sh` + RCON）实测调整。特别警惕「放大机制叠加导致某一档过强」或「增殖链卡死无法产出」。
5. **爆炸威力上限**：`explode()` 有硬上限 100f（`NuclearReactorBlockEntity.kt:1452`）。T4/T5 的灾难级爆炸若要更大需放开此上限（谨慎，可能破坏领地）或改用「辐射云 + 区块污染」表达而非物理爆炸。
6. **ASA 数值不动**：本方案不削 ASA，只抬核电。若未来要平衡 ASA，应单独评估（削 Neutron 会得罪已投资的玩家）。增强核电是更安全的方向。
7. **辐射系统的可玩性**：辐射污染若设计不当会变成纯惩罚（玩家被恶心而放弃）。必须配套「屏蔽结构有效」「去污机可清理」「辐射有视觉反馈」，让玩家感到「可控的风险」而非「随机灾难」。
8. **聚变堆与裂变堆的区分**：聚变必须用**独立多方块结构**（不复用裂变腔），否则机制混淆。聚变的「温度窗口」玩法与裂变的「热量池」玩法本质不同，强行合并会两边都做不好。
